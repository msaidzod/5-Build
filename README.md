# Indie Film Collective

## Project Description

A four-page website for a creative community of independent
filmmakers, storytellers, and visual artists. It introduces
film screenings, filmmaking workshops, and collaboration
opportunities.

The website uses semantic HTML, consistent relative navigation,
and a shared mobile-first stylesheet. A media query at 800px
changes the navigation, sidebar, and homepage card layouts
for larger screens.

## Pages

- index.html — Homepage introducing the collective.
- screenings.html — Film screening information and activities.
- workshops.html — Workshop topics and filmmaking exercises.
- collaborations.html — Collaboration opportunities and project planning.
